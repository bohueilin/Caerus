## 1. 一句话结论

> Sunday 的团队是世界级的，"人类戴手套采集数据→训练家务机器人"这条路线在研究上已验证到"单任务近乎可靠"的程度。但它的商业生意还没有开始：零收入、零交付，硬件以接近成本价出售。B 轮投后 **$1.15B**，是"家用通用机器人"这张期权的入场价，有 1x 优先清算权保底。按基本面，*合理价值约 $0.8–1.3B，保守价值约 $0.45B*。对后来者，当前价格没有安全边际。**结论：观望。** 感恩节前 Beta 是否真实交付、以及是否披露人工干预率，是第一个验证节点。 🔴

## 6. 各维度分析摘要

**商业模式（business-decoder）**
1. 生意本质：*用"人类戴手套干家务"的廉价数据训练一个能叠衣、洗碗、收拾的机器人，卖给高收入家庭替代部分家政时间。* 🔴（推理）
2. 量产成本约 $10k，目标售价约 $10k，**硬件近乎零毛利**，利润只能来自技能订阅。订阅结构未公布 🟡。
3. 数据飞轮是"花钱买数据"（采集员时薪 $30–60），不是"用户越多数据越多"；公司又承诺不用用户家中数据训练，**飞轮的复利效应被削弱** 🟢/🟡。
4. 护城河：窄，且只是潜在的。数据、品牌各 ★3，其余 ★1。

**财务（financial-detective）**
1. 账上现金约 $125–155M，跑道约 18–22 个月，*大概率 2027 年上半年融 C 轮（$300–600M）* 🔴。
2. 优先清算总额约 $200M。*退出价值低于 $200M 时普通股接近零* 🔴（条款推测）。
3. 五种估值方法没有收敛：市场法 $1.0–3.0B，基本面法 $0.2–1.0B。差额就是"赛道期权 + 团队稀缺溢价"。🔴（各方法均为推算）

**竞争（competitive-mapper）**
1. 行业吸引力当前 ★2，10 年视角 ★4。没有一家公司有独立验证的规模化家庭交付数据。
2. **FCC Covered List（2026-07-28）** 限制境外生产的新型号机器人进入美国，对美国本土整机商构成政策护城河 🟢（规则）/🟡（是否覆盖轮式）。
3. 数据路线正在趋同：Figure 靠纯人类视频，把零样本成功率从 9% 提到 56%；PI 开放 API；Generalist 用可穿戴"data hands"，号称 50 万+ 小时。*手套优势窗口约 12–24 个月。* 🔴
4. 2031 年情景：胜出 15–20%，共存或被并购 45–50%，被颠覆 30–35%（主观判断）。 🔴

**风险与治理（risk-governance-analyst）**
1. 创始人：Zhao ★3.5，Chi ★4。没有争议事件；第一次创业、没有量产经验。
2. **结构性短板**：没有具名的硬件量产、供应链、消费者运营或安全合规负责人，这正是 Jibo、Anki、Rethink 失败的地方。
3. 失败路径：量产与单位经济失败（约 20%）；卡在长尾可靠性、被大厂收编（约 15%）；被资本碾压、融资断供（约 10%）。 🔴
4. 最可能的退出：2027–2031 年被战略并购；IPO 概率约 15%。并购也有障碍：Amazon 收购 iRobot 被反垄断叫停的先例。 🔴

**技术与知识产权（tech-ip-analyst）**
1. 架构：*Transformer + 动作分块，可能加扩散头*；手套与机器人手几何同构，再用 Skill Transform 转换成机器人数据（官方称 90%+ 可转换）🟡。
2. **专利权属错位**：Diffusion Policy、UMI 的专利归 TRI（UMI 已授权，US12623350B2），Transformer 扩散方法的专利归 DeepMind。存在低概率但需关注的 FTO（自由实施）风险 🟢。
3. 演示加速已被官方承认；机器人速度约为人类的 50–75% 🟢。
4. 模型层会被开源 VLA（π0.5、GR00T）商品化。Sunday 的价值必须落在"系统 + 产品 + 部署"上。

**替代数据（signal-miner）**
1. Fidelity N-PORT 揭示 B 轮每股价格和交割日。Fidelity 被宣传为主要投资方，**实际出资约 $1.43M（$1,433,218 ÷ $165M ≈ 轮次的 0.87%）** 🟢。
2. CoreWeave Q2 2026 财报把 Sunday 列为新客户（算力供应方）🟢。
3. 消费端 API 于 2026-08 进入生产环境（证书透明日志），Shopify 结账已就绪但加锁，是**交付准备的正面数字证据** 🟢。

## 7. 真实价值评估

### 第一性原理四问

| 问题 | 回答 |
|---|---|
| **1. 真需求还是伪需求？** | **真需求，但支付意愿未验证。** 美国家庭每年在保洁和家务上的支出巨大（人类保洁：每周一次约 $9.6–12k/年，双周一次约 $4.2–5.7k/年；按 Thumbtack 单次 $185–230、Housecall Pro 单次 $140–220 推算），时间稀缺是真痛点。可是 Jibo、Anki、Kuri 的历史说明，"可爱/新奇"不等于"刚需"。机器人必须**可靠完成一组足够有价值的任务**，用户才肯付 $10k。经济下行时，一台 $10k 的家用机器人是**可被砍掉的可选消费**。 |
| **2. 为什么是这个团队？** | 两位创始人分别发明了当前机器人学习的两大主流范式（ACT/ALOHA 与 Diffusion Policy/UMI），手套路线就是 UMI 的产品化。这是**全球极少数能把研究前沿直接转成数据管线的团队**。短板同样明显：零硬件量产、零消费品经验。 |
| **3. 天花板与死法** | 天花板：*家用通用机器人若成为新品类，前二玩家的终局估值可达 $40B 以上*。最可能的死法：**单位经济与可靠性长尾**。每步 99% 成功率，20 步任务的成功率只有约 82%；每次失败都需要远程协助或上门服务，吃掉本就接近零的硬件毛利。 🔴 |
| **4. 关键验证节点** | ① 2026-11-26 前 Beta 真实入户；② 公开人工干预率与多任务成功率；③ 2027 年 C 轮定价与领投方；④ 2027 年量产 BOM ≤ $10k、明确的代工伙伴；⑤ 订阅定价与首批付费留存。 |

### 生意本质判断
- **一句话**：*一家用 AI 研究能力去攻打"消费级硬件 + 现场服务"这门苦生意的公司。*
- **确定性**：低。技术确定性中等（单任务已接近可靠），商业确定性很低（定价、成本、服务、需求全部未验证）。
- **段永平式判断**：*"对的生意"要求有护城河和定价权。消费硬件天然面临价格战（看看扫地机器人和 iRobot）。Sunday 只有在软件或技能订阅上建立粘性，才可能是对的生意；目前看不出来。现阶段它是"对的团队，做一门还不知道对不对的生意"。*

## 8. 投资论点

### 🟢 看多逻辑
1. **团队稀缺性**：两大机器人学习范式的发明者同在一家公司，人才吸引力强（10,000+ 求职申请，Tesla 系 10+ 人加入）🟢。
2. **数据成本优势**：手套约 $200–400，遥操作设备约 $20k，*数据采集成本低约 1–2 个数量级*，而且直接采自真实家庭 🟢/🟡。 🔴
3. **技术进展快**：ACT-1 到 ACT-2 约 8 个月；在未见过的家庭中叠衣成功率 99.1% 🟢（公司口径）。
4. **形态务实**：轮式双臂比人形更便宜、更安全、更易量产，适合家用 🟡。
5. **政策红利**：FCC 规则把形态最接近的中国整机挡在美国市场外 🟢/🟡。
6. **资本面健康**：约 $200M 现金，18–22 个月跑道，顶级 crossover 基金进入，Fidelity 小幅上调标记 🟢/🔴。
7. **相对估值不贵**：估值/融资 5.75x，明显低于 The Bot Company 和 1X 🟢。

### 🔴 看空逻辑
1. **零收入、零交付就到 $1.15B**，感恩节承诺 5 周前仍无任何交付证据，官方 8 月中以来静默 🟢。
2. **单位经济倒挂**：成本约 $20k，目标售价 <$10k；量产后硬件毛利约为零，订阅模式未公布 🟢/🟡。
3. **知识产权空心**：核心算法专利不归公司，自有专利被驳回，手套路线已被 Generalist 等复制 🟢。
4. **组织缺"苦活"能力**：没有量产、供应链、客服、现场服务负责人，财务由外部记账 🟢。
5. **资本悬殊**：Figure 累计融资约 $1.9B、估值 $39B；Tesla、Amazon、Google 都可能入场 🟢。
6. **叙事与事实有张力**："零遥操作"与遥操作团队并存；没有 Form D；隐私政策不覆盖机器人；演示加速 🟢。
7. **历史基率很差**：Jibo、Anki、Kuri、Rethink、Everyday Robots 全部失败，iRobot 破产时普通股归零 🟢。

### ⚖️ 哪一方更有说服力
**短期（12 个月）看空论据更硬**，因为都是可验证的事实缺位：没有交付、没有定价、没有组织能力。看多论据主要是"团队和方向对"，属于长期期权。**两者并不矛盾：这是一张好期权，但现在的价格是期权价，不是价值价。**

## 14. 总结

Sunday Robotics 本质上是一家**用顶级机器人学习能力，去攻打"消费级硬件 + 家庭现场服务"这门苦生意**的公司。它最大的确定性是团队：两位创始人分别发明了当前机器人学习的两大主流范式，手套采集路线让它能以远低于遥操作的成本，获取真实家庭数据。ACT-2 叠衣服 99.1% 的成绩说明技术方向成立。它最大的不确定性是生意本身：截至今天零收入、零交付，量产后硬件近乎零毛利，订阅模式未公布，知识产权空心，组织里缺少量产和服务能力。家用机器人的历史基率（Jibo、Anki、iRobot）也很差。

$1.15B 的 B 轮价格，是同行期权定价加优先清算保护下的合理"入场券"，但不是基本面价值。*我们判断合理价值约 $0.8–1.3B，保守约 $0.45B；按当前价格买入，概率加权年化约 13%，没有安全边际。* 🔴

**最终建议：观望。** 感恩节前后的 Beta 交付和人工干预率披露，将决定乐观情景能否成立。如果 2027 年 C 轮之前看到"真实入户、可靠的多任务、BOM 达标"三项证据，值得以领投方身份带条件参与；二级市场的普通股或期权转让应回避。
