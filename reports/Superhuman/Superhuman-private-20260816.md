## 4. 核心业务：已被商品化，且是公司自己承认的

### 4.1 措辞漂移——最锋利的证据（🟢）

| 位置 | 现在的措辞 |
|---|---|
| grammarly.com 首页 H1 | "Think big. We'll take care of the details." |
| 副标题 | "Work with an **AI partner** that helps turn your thoughts into writing…" |
| **是否出现 "grammar checker" / "spelling"** | **首页主视觉完全不出现** |
| Free 层功能表 | 仍写 "Write without spelling and grammar mistakes" |
| superhuman.com H1 | "AI that works where you do." |
| **"Grammarly" 的新定位** | **成为 Superhuman Go 里的一个 agent**（与 Email Assistant、Knowledge Checker、Daily Brief 并列） |

> *【推理】* **漂移方向极其明确：语法/拼写这一原始价值主张已被推到免费层的功能项，付费叙事整体上移到 "AI partner / agent"。**
>
> **更关键的是——"Grammarly" 在新架构里不再是产品，而是 Go 里的一个 agent 名。一个品牌从"公司名"降级为"agent 名"，是最直白的核心降级信号。**

### 4.2 差异化主张：不是"写得更好"，是"到得更全"

官网现在的三条差异化**全部是分发/嵌入，没有一条是模型能力**：
1. **无处不在**：Go 覆盖 Mac/Windows 桌面、Chrome/Edge 扩展、iOS，嵌入 Gmail、Slack、Google Docs
2. **不换工作流**："works where you do"——卖点是不用切到 ChatGPT 窗口
3. **企业级**：17x ROI、人均年省 $5,000（**纯公司自述、无方法论**）

> *【推理】* **这正是被商品化企业的典型防线：当"写得更好"打不过 ChatGPT/Copilot 时，退守"我在你已有的窗口里"。**
>
> **但这条护城河的问题在于——Copilot 原生在 Word/Outlook 里，Gemini 原生在 Google Docs/Gmail 里，二者的"无处不在"是 OS 级和套件级的；而 Grammarly 的"无处不在"靠浏览器扩展和覆盖层，是寄生式分发，随时可被宿主收回。**

### 4.3 定价证据：降价 + 功能下放，两条都命中（🟢）

**当前定价**（grammarly.com/plans 与 superhuman.com/plans **已是同一套定价**）：

| 层级 | 价格 | 覆盖 |
|---|---|---|
| **Free** | $0 | **AI chat 跨应用、20+ 语言写作辅助、协作 Docs、有限 Go、每月 100 次 AI prompt** |
| Pro | **$12/mo 年付；$15/mo 月付** | 无限改写/翻译、AI 检测、品牌定制 |
| Business | **$33/mo 年付；$40/mo 月付** | + Mail 全功能、HubSpot/Salesforce/Pipedrive、Jira/GitHub/Figma 同步 |
| Enterprise | Custom | + 分析、SAML SSO、DLP、BYOK |

**定价权流失的三条证据**：

1. **月付价腰斩**：历史月付约 $30（🟡 未验证），现为 $15。**年付锚点纹丝不动而月付砍半——典型的"不敢动明面价、只能砍实际支付价"。**
2. **功能大幅下放免费层**：Free 层现含 **AI chat、协作 Docs、Go 访问权、每月 100 次 AI prompt**。**把生成式 AI 白送，说明它已不是可收费的稀缺品。**
3. **同价打包四个产品**：$12 现在买到 Grammarly + Docs + Go + AI chat。**单位价格不变、交付内容翻数倍 = 实质性大幅降价。**

*Superhuman Mail 独立售价历史上约 $25–30/席/月（🟡 未验证）；现在 Business $33 里包含 Mail + Grammarly + Docs + Go——**等于用 Mail 的原价把整个套件送了出去**。*

### 4.4 Superhuman Go：新叙事的核心，却不单独收费也没有客户

- **形态**：不是独立 App，是**覆盖层**——inline 建议、side panel、cursor actions、定时自动化；可定制 agent 团队，通过 **MCP connectors** 接数据源
- **状态**：已 GA
- **定价**：**没有独立定价，"included in all Superhuman plans"**（🟢）
- **客户证据**：**未检索到任何 Go 的具名客户案例**（🔴）

> *【推理】* **免费打包一个"旗舰"产品且拿不出一个具名客户，通常意味着它在做防守性留存，而非增量变现。**

## 5. roll-up 的性质：有序撤退，不是扩张

### 5.1 整合程度：已完成品牌吞并（🟢）

- **coda.io/pricing 现 307 重定向至 superhuman.com/docs/pricing**——Coda 域名已实质废弃
- 官方博文："Coda is now **Superhuman Docs**… a new name and visual identity that bring us closer to a **unified suite** with Mail, Go, Grammarly, and more"
- **统一定价与账号**：一个 Free/Pro/Business/Enterprise 阶梯覆盖全部产品
- grammarly.com 与 superhuman.com 共用同一套价格表

**整合执行得相当彻底——这不是拼凑。但整合彻底 ≠ 战略正确。**

### 5.2 命名策略：最关键的一条推理

**用被收购方（Superhuman，一个 2025 年被收购的小众付费邮件客户端）的名字，替换掉 4,000 万用户认知的 Grammarly——且 Grammarly 被降级为 Go 里的一个 agent 名。**

> *【推理】* **正常的 roll-up 会保留强品牌。此处反向操作，唯一自洽的解释是：管理层评估认为 "Grammarly" 的品牌资产已是负资产——它把公司锁死在"廉价语法检查器"的认知里，而这个品类正被 LLM 免费化。**
>
> **改名不是升级，是弃船。**

### 5.3 与 Inworld AI 模式的同构检验

| 撤退型 roll-up 特征 | Superhuman |
|---|---|
| 核心品类被通用模型商品化 | ✅ 语法/写作辅助 |
| 靠收购扩张品类 | ✅ Coda(2024-12) + Superhuman(2025-07) |
| 把撤退包装成扩张 | ✅ "unified suite"、"AI that works where you do" |
| **淡化/掩埋原核心品牌** | ✅ **改名 + Grammarly 降级为 agent** |
| 新叙事无独立定价、无收入证据 | ✅ Go 免费打包、零具名客户 |
| 核心指标停止披露 | ✅ 官网现无任何 ARR 数字 |

**六项全中，且"掩埋核心品牌"这一步比 Inworld 更彻底。**

> **但与 Inworld 有一个重要区别：Superhuman 的撤退是有序撤退。** 套件整合真实完成、新战场（AI 工作台）逻辑自洽、$7 亿 ARR 与 4,000 万分发面是真实弹药。
>
> **风险不在"拼凑"，而在于撤退的终点是 Microsoft 365 Copilot 与 Google Workspace 的主场——从被 LLM 商品化的窄品类，撤退进一个被两家万亿美元公司原生占据的宽品类。**

## 8. GC 的 $10 亿非稀释融资：为什么不是股权？

**GC 官网 CVF 页面**（generalcatalyst.com/capital，🟢）原文定位：

> "Why should equity be the only solution to grow in your market?... Acquiring new customers post product-market fit has never been more scalable."

配套文章标题：**"The Unbundling of 'Growth' Equity"、"Financed to Endure"、"Yield is All You Need"**。

> **CVF 明确自我定位为成长股权的替代品，面向"已过 PMF"的公司——话术上完全支持"主动选择"的解释。但通篇无一字排除"融资困难"场景：它恰恰是把"不想/不能按旧估值定价"包装成财务纪律的产品。**

### 判断：**回避 down round（B）65% / 主动选择（A）35%**

**支持 B 的决定性证据是 BlackRock 的 marks**：
- 2025 年 GC 放款时，Grammarly 的第三方公允价已比 C 轮低 **56–61%**
- **任何 2025 年的定价股权轮都必然是幅度巨大的 down round**，会触发反稀释棘轮、重定员工期权（1,292 名持有人）、并向市场坐实估值腰斩
- **用不重设估值的收入类信贷绕开这一切，是唯一理性选择**
- 且 $10 亿 ÷ $7 亿 ARR = **1.43× ARR 的类债务负担**，对一家增速仅约 12–15% 的公司**规模异常激进**——不像"顺手补充营运资金"，更像"股权通道关闭后的唯一大额弹药"

**保留 A 的 35%**：Hemant Taneja 五年连任董事，GC 是深度内部人；**CVF 回报封顶意味着 GC 并未借机攫取股权折价**——这与"趁火打劫的救援融资"不同，确有真实的资本结构优化成分。

**能区分两者的四项证据（目前全部不可得，🔴）**：① 2025 年是否存在被放弃的 term sheet；② CVF 的实际票息/回报上限倍数（>1.5× 偏 B，≈1.2× 偏 A）；③ 是否附带优先清算权或转股条款；④ **员工期权行权价（409A）在 2025 年是否被下调——BlackRock marks 已强烈暗示是。**

## 15. 总结

**这门生意的本质**：Superhuman 卖的是"不换工作流的、跨所有应用的 AI 助手"。它曾经卖的是"把你的字写对"——**而那个东西现在是免费的，包括在它自己的免费层里。**

**核心是否被商品化：是，且是公司自己承认的。** 判定依据不是外部评论，而是三个自身动作：把语法/拼写/AI 生成全部下放免费层；首页彻底删除 "grammar checker"；**把 "Grammarly" 从公司名降级为 Go 里的一个 agent 名**。定价证据（月付 $30→$15、同价交付四倍内容）进一步坐实。

**roll-up 的性质：有序撤退。** 与 Inworld 模式六项特征全中，且"掩埋核心品牌"更彻底。但执行质量明显更高——套件整合真实完成，新战场逻辑自洽。**问题在于撤退的终点是 Microsoft 365 Copilot 与 Google Workspace 的主场。**

**真实价值判断**：**$38–65 亿，中枢约 $50 亿；相对 2021 年的 $130 亿需下修 55%–70%。** 这个结论的置信度是本系列研究中最高的——**因为它不是分析师推算，而是参与那一轮定价的 BlackRock，在受监管的季度申报中逐季标记的：$26.21 → $7.67，−70.7%。**

**最大的确定性**：估值重定价已经发生并被第三方逐季记录。**最大的不确定性**：GC 那 $10 亿的实际条款——它决定了在这个已经缩水 70% 的股权价值里，普通股和员工期权还剩多少。**而 Neuberger 的数据已经给出了一半答案：优先股几乎持平，普通股跌了 56%。**
