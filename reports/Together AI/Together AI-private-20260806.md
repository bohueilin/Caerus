## 1. 一句话结论

Together AI 是一家由一流技术团队经营、按软件公司定价、但收入大头是 45% 毛利 GPU 租赁的两栖公司。它抓住了开源推理这个真需求且执行力顶级，但护城河最浅处（转换成本近零）决定了整体深度，最强武器（FlashAttention）被自己开源。**合理价值 $6–7B，保守价值 $4–5B，当前 $8.3B 无安全边际。结论：观望。**

## 4. ⚠️ 反偏见检查：单源依赖警告（最重要的方法论发现）

在汇总阶段发现一个**六份报告都没有单独察觉的系统性问题**：

**本案最载重的三个数字，全部只有一个来源——付费研究机构 Sacra 的估算。**

| 关键数据 | 来源数量 | 实际来源 |
|---|---|---|
| 收入结构 60–70% GPU 租赁 / 30–40% API | **1** | Sacra |
| 综合毛利率 ~45% | **1** | Sacra |
| 2025 年末收入 $618M | **1** | Sacra |

六个 Agent 独立研究后都引用了同一个数字，在汇总时**看起来像六重交叉验证，实际上是一重**。而这三个数字恰恰是全部结论的地基：

- 「这不是软件公司是 neocloud」← 建立在 60–70% 这个单源数字上
- 「估值应按算力资产定价」← 同上
- business-decoder 反推的「自有算力 ≈ 26%」← 用 45% 毛利率反推，也是单源

**处理方式**：本报告保留这一判断（因为它与四条独立证据方向一致——招聘结构、投资人构成、媒体归类、自建数据中心动作），但**明确标注其定量精度不可靠**。若 Sacra 的拆分有误（例如实际是 50/50），估值中枢应上修 15–25%。

**这正是未上市公司研究最典型的陷阱**：多个信息源看似独立，实则共同上游。列入信息盲区第一位。

### 5.3 信息拼图：把碎片合起来看到了什么

单看任何一份报告都看不到的三个发现：

**拼图发现 1：零债务 + 表外 capex + 零销售 = 一个自洽的商业机器**

- signal-miner：零销售招聘，投资人全是能源与硬件
- financial-detective：无任何 GPU 抵押债务记录，资本效率 0.75x（同业最优）
- risk-governance：500MW 由投资人独立出表资本化，Hypertec/5C 联盟"最高 $5B"
- business-decoder：自有算力仅约 26%，其余为转租

**合起来**：Together 的模式是——**用股权和合作方资本（而非自有债务）撬动产能，用创始人/合作伙伴关系（而非销售团队）签超大合约**。这解释了它为什么资本效率优于所有同业，也解释了为什么它不需要销售漏斗。

这是**真正的差异化，也是真正的脆弱点**：它的增长依赖于「持续有合作方愿意出资建设 + 持续有超大客户愿意签长约」。任一环断裂，"5 年扩产 50 倍"立刻停摆，而 $800M 股权绝对不够独立支撑。**"没有债务"是好消息，但不等于"低杠杆"——杠杆在别人的资产负债表上，条款不透明。**

**拼图发现 2：45% 毛利率之谜已被解开，但揭示了更坏的事**

business-decoder 用 `0.65x + 0.38(1−x) = 0.45` 反推出自有算力约 26%——与 Sacra 的定性描述吻合。这化解了 financial-detective 标记的"折旧前/后"致命盲区。

**但解开后看到的是**：Together 当前四分之三的算力是**转租**，而转租段毛利仅 37–40%，且**完全没有壁垒——上游 CoreWeave/Lambda 随时可以自己做零售**。$800M 的真实用途，是把这个比例推上去。

配合 business-decoder 的利用率敏感性表：

| 利用率 | 自有机房毛利率（B200，5 年折旧） |
|---|---|
| 100% | 79% |
| 60% | 65% |
| 40% | 48% |
| 25% | 16% |
| **20%** | **−4%（亏损）** |

**这是一个没有中间状态的双向赌注**：自建成功且利用率 ≥60% → 综合毛利向 55–65% 迁移，估值逻辑重写；自建超支或 AI capex 转向导致空置 → 刚性折旧 + 价格战双杀，毛利塌陷。

**拼图发现 3：那笔 >$10 亿的合同可能是整个论文的单点故障**

四份报告从四个方向指向同一个黑洞：

- financial-detective：若为 3–5 年期，当年贡献 $200–330M，却 100% 计入 bookings
- business-decoder：若为 3 年期，单一客户可能占年收入 25–33%
- signal-miner：零销售招聘 + 开发者声量与 $1B 收入严重不匹配，都指向收入极度集中
- risk-governance：已知客户（Cursor、Cognition、Decagon）全部是 VC 输血、尚未盈利的 AI 初创，且与 Together 共享投资人

**客户身份从未公开，在任何媒体报道中也从未被追问过。** 这是本案最大的未定价风险。

## 7. 真实价值评估

### 7.1 生意本质

**用最朴素的话讲**：英伟达的卡很贵、很难买、很难用好；开源模型免费但自己部署会死得很惨。Together 把卡买来（或租来）、把开源模型调到跑得又快又便宜、打包成一个 API 或一个集群卖给你。

**这是不是一门"对的生意"？**

- ✅ 需求是真需求：开源推理的需求 10 年后一定还在
- ✅ 时点抓得极准：2022 年押注开源推理，是过去四年最正确的赌注之一
- ❌ **但生意的底层物理是不利的**：上游 NVIDIA 通过配额+CUDA+循环融资拿走 70–80% 利润池；下游产品完全可替代（OpenAI 兼容 API，改一行 base_url）；降本红利（Blackwell 10x）四家同时获得，必然全额传给客户
- ❌ **这不是抗周期生意**：训练/集群侧（60–70%）绑在客户研发预算上，是 AI capex 周期的高 beta 表达

**确定性判断**：生意本身的确定性中等偏低。**"开源模型托管这个需求 10 年后一定在，但 Together 是否还是那个收租的人，是个开放问题。"**

**综合护城河评级：★2.5 / 5 —— 窄且脆弱（Narrow and Fragile）**

> **护城河的深度由最浅处决定。** 一个客户可以在 30 分钟内把 40% 收入来源（serverless）迁走。品牌（★4）与规模经济（★4）是真支柱，但转换成本（★2）与数据壁垒（★2）在这个商业模式里**结构性地无法变强**——因为核心资产（kernel）被开源，核心数据（客户流量）不可用于训练。

## 8. 投资论点：看多 vs 看空

### 🟢 看多逻辑

1. **估值倍数三轮连续压缩而估值上涨 6.6 倍**（42x → 33x → 8.3x）。这是一级市场最健康的形态——基本面跑赢估值，没有透支。对照 2021–23 那批倍数不降反升的 AI 公司，Together 的估值结构是干净的。🟢
2. **资本效率同业最优**：收入/累计融资 = 0.75x，vs Fireworks 0.53x、CoreWeave IPO 前 <0.3x。用更少的钱做出了更多的收入。🟢
3. **零 GPU 抵押债务**，而 CoreWeave（$3.1B）、Nebius（$775M）都有。在 neocloud 普遍靠债务续命的 2026 年，这是稀缺的资产负债表质量。🟡
4. **技术能力是真的**：19 篇顶会论文（Mamba-3 为 ICLR Oral），FlashAttention-4 快过 NVIDIA cuDNN 22%。创始科学家在一线出论文，不是挂名壳。🟢
5. **老股东连续加注**：NVIDIA 四轮全参、Salesforce Ventures 三轮、General Catalyst/Emergence/Kleiner 复投。Vista Equity（PE 属性，通常只在接近可预测现金流的资产上出手）首次入场。🟢
6. **管理层清楚问题所在且在正确应对**：向自建纵向一体化（毛利 38%→65%+）、把按量收入转为容量合同（PTU/长约）、横向扩到比价不充分的多模态与 RL 品类。产品迭代方向全部对准正在增长的品类。🟢
7. **相对折价可能过头**：同等 ARR 的 Fireworks 值 $17.5B。若 Together 的 API 段被单独定价，仅这一段就值 $4.9B。🟡

### 🔴 看空逻辑

1. **市场已经用 2.4 倍的倍数差做出裁决**。同月融资：Fireworks 17.5x、Together 7.2x，而 Together 收入更大。**折价不是机会，是诊断。**🟢
2. **行业吸引力 ★1.7/5**。五力平均 4.6：NVIDIA 拿走 70–80% 利润池，产品完全可替代，降本红利 100% 传给客户。这是教科书级的完全竞争商品市场。🟢
3. **技术优势换不成利润**：拥有行业顶级推理优化能力，却在 Llama 3.3 70B 上比 Groq 贵 40%、比 Fireworks 贵 15%。**最强武器被自己开源了。**🟢
4. **增长质量存疑**：59 岗中零销售，一笔 >$10 亿的合同，开发者声量与 $1B 收入严重不匹配。**增长不来自可复制的引擎，而来自少数巨型合约，续约风险极度集中。**🟢
5. **利用率是悬崖式变量**：跌破约 30% 即刻亏损。而"5 年扩产 50 倍"意味着产能会先于需求到位。🔴（推算）
6. **5 个创始人只有 1 个是纯全职运营者**。Chris Ré、Percy Liang 纯挂名；CTO 与 Chief Scientist 均为高校终身轨双聘。技术护城河系于一位 Princeton 助理教授身上。🟢
7. **下行情景普通股回收为零**：优先股 $1.33B 在前，GPU 残值与清算时点完美负相关（行业下行期二手市场同时崩塌）。**收益结构不对称向下**——上行需要几乎所有事情都对，下行只需一件事出错。🔴（推算）

### ⚖️ 哪一方更有说服力？

**看空方更有说服力，但不是因为公司差，而是因为价格。**

看多的七条里，有五条（估值倍数压缩、资本效率、无债务、技术真实、老股东加注）**说的是"这家公司比同业管理得好"**——这些我全部认可。但它们回答的是"这是不是一家好公司"，而不是"$8.3B 值不值"。

看空的七条里，有四条（行业吸引力、技术换不成利润、市场倍数裁决、增长质量）**说的是"这门生意的物理结构不利"**——而生意的结构比管理层的质量更难改变。

**决定性的一条是第 3 条与第 4 条的组合**：一家拥有世界第一梯队推理优化能力的公司，产品定价却高于两个主要对手，且增长依赖不可复制的超大合约。**这说明它的技术优势没有转化为任何形式的经济护城河。** 段永平会问"这门生意的钱是怎么赚的"——Together 赚的是资本套利和运营效率的钱，不是护城河的钱。

### 盲区对结论可靠性的影响（诚实声明）

> **在「收入结构与毛利率仅有单一来源（Sacra）」、「客户集中度完全未知」、「表外结构条款不透明」这三项信息缺失的情况下，本报告估值区间（$6.5–7.0B 合理 / $4.2–4.9B 保守）的置信度为「中」。**
>
> 具体而言：
> - **方向性结论（这是 neocloud 不是软件公司、$8.3B 无安全边际、观望）置信度高**——因为它由六条相互独立的证据链支撑（招聘结构、投资人构成、市场倍数、媒体归类、自建动作、定价劣势），不依赖任何单一数据源。
> - **定量结论（$6.5–7.0B 这个具体数字）置信度中等**——它依赖 Sacra 的收入拆分。若实际拆分是 50/50 而非 65/35，合理估值应上修至 $8–8.5B，届时当前估值就是合理而非偏贵。
>
> **读者应把本报告的估值当作区间判断而非点估计使用。**

## 14. 总结

Together AI 的生意本质，是把英伟达的卡和免费的开源模型，加工成开发者和企业能直接用的东西来收租。这门生意的需求是真的，赛道抓得极准，团队是这个领域最好的技术团队之一——FlashAttention 系列不是公关包装，19 篇顶会论文和创始科学家的实名署名都是硬证据。它的资本效率是全行业最优（0.75x），估值倍数三轮连续压缩（42x→33x→8.3x）说明基本面跑赢了估值，而且它是同业中唯一一家没有 GPU 抵押债务的公司。

但六个独立视角最终收敛到同一个判断：**这不是一家 AI 软件公司，是一家有顶级软件团队的 neocloud。** 六成到七成的收入来自 45% 毛利的算力租赁；最强的技术武器被自己开源，导致它拥有世界第一梯队的推理优化能力，定价却高于 Groq 40%、高于 Fireworks 15%；59 个在招岗位里没有一个销售，而账上有一笔从未公开客户身份的、超过十亿美元的合同。市场在同一个月给了 ARR 相近的 Fireworks 17.5 倍、给了 Together 7.2 倍——这个 2.4 倍的差距不是错杀，是对资产结构的准确诊断。

**最大的确定性是需求**：开源推理这件事十年后一定还在。**最大的不确定性是"Together 是否还是那个收租的人"**——它的护城河最浅处（转换成本近乎为零）决定了整体深度，而这一项在这个商业模式里结构性地无法变强。

$8.3B 隐含的假设是"它最终会变成软件公司"，而这需要 API 收入占比从 35% 升到 55% 以上。**目前没有任何公开证据显示这个比例在上升。** 合理价值 $6.5–7.0B，保守价值 $4.2–4.9B，当前估值无安全边际。**结论：观望。** 若二级市场出现 $5B 以下的可成交价格，或分部收入首次披露且 API 占比超过 45%，值得重新评估。
