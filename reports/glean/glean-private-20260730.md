# Glean 未上市公司深度研究报告

**研究日期**：2026-07-30
**研究方法**：6 个并行研究 Agent（商业模式 / 财务估值 / 竞争格局 / 风险治理 / 技术知识产权 / 替代数据信号）+ team-lead 交叉验证与仲裁
**标注规范**：🟢 高置信（一手/官方/API 直抓）｜🟡 中置信（单源或二手）｜🔴 低置信（推算）｜*斜体 = 推理*

> ⚠️ **两项前置声明**
>
> **① 研究方法的意外收获**：本会话 WebSearch 配额在研究开始前已耗尽（200/200）。6 个 Agent 全部改用直抓一手数据源——**结果质量高于典型的搜索驱动研究**。关键突破包括：Glean 官方定价文档全文（`docs.glean.com`，标注更新于 2026-07-28）、Greenhouse 招聘 API 全量 102 条 JD 含薪酬带、GitHub/npm 生态数据、Wayback 客户 logo 三期 diff、MCP 规范原文、NVD CVE 全库检索。
>
> **② 系统性正向偏差警告**：G2、Gartner Peer Insights、TrustRadius、Reddit、Glassdoor、Blind、Forge、Hiive、Notice.co **全部 403 封锁**。这意味着本报告约 70% 的公司侧数据来自 **Glean 自己控制的页面**。**没有任何独立第三方对产品质量、部署失败率、客户抱怨、续约情况的证词。** 这是本报告最严重的结构性缺陷。

## 1. 一句话结论

Glean 是本框架研究过的三家 AI 公司中**生意质量最好的一家**——真 SaaS 毛利、已自我完成 per-seat 到消费定价的转型、把 LLM 成本做成了转嫁项而非 COGS。$7.2B 对应 24x ARR / 18.7x NTM，与 2026 年高增长 SaaS 中位数 18.4x 几乎重合，**倍数本身不贵**。但它占据的是三个万亿平台之间的缝隙，行业结构评分仅 ★1.5/5。合理估值 **$6.5–7.5B**，一级价格基本公允，**二级市场已溢价至安全边际归零**。

### 🔍 四处关键仲裁

**仲裁 A：毛利率（69% vs 85–92%）——本报告最重要的一处，结论被翻转**

| 分析师 | 判断 | 证据类型 |
|--------|------|---------|
| financial-detective | 毛利 ~69%（54–78%），LLM 推理是 COGS 拖累 | 推算，无披露 |
| **business-decoder** | **LLM 成本是转嫁项 + take-rate 收入线**，订阅毛利 85–92% | **官方定价文档一手** |

**采信 business-decoder。** 证据是文档逐字：

> Model Hub Usage "**Charged at model or hosting provider API rates**"（46 个模型价目表全公开，原价透传）
> 叠加 "**Flexible Model Management — Fee: % of total LLM usage**"（在客户的 LLM 成本上再抽成）

三条硬性成本工程佐证：① 自研 **Waldo** 便宜 10 倍，专做最高频的检索规划环节；② 引擎 V1→V2 实测单查成本降 39%；③ **Premium 模型（Opus 5 / GPT-5.5+）永不含在座位内**，硬性围栏防止高端推理击穿座位毛利。

**修正后的判断**：订阅毛利 85–92%，但**混合毛利 72–82%**——Forward Deployed Engineer（3 地在招）、Resident Solutions Architect、Designated TSE 的 Palantir 式重服务模式会拉低毛利并降低可规模化程度。

> **这个仲裁实质改变了估值结论。** 毛利从 69% 上修到 85%+，可比倍数区间整体上移，Glean 从"低于可比组中位"变为"符合甚至优于"。**"AI 应用公司毛利会被推理成本吃掉"这一共识，在 Glean 身上有据可查地不成立。**

## 6. 真实价值评估

### 6.1 生意本质判断

> **一句话**：Glean 用工程重资产（153 个权限感知连接器 + 知识图谱）建了一个别人懒得建、也不敢建的企业数据接入层，然后按人头收地板费、按 AI 用量收增长费、按合规收保险费。

**段永平式判断：这是一门"真生意"，不是"故事生意"。**

三件事让它区别于绝大多数 AI 应用公司：
1. **它不承担 LLM 成本**（原价透传 + 抽成）——模型降价它受益，模型涨价它也受益
2. **它已完成 per-seat → 混合消费的定价迁移**，而不是等着被这个趋势碾过
3. **它的毛利保护是工程性的**——Waldo 把最高频环节成本降了 10 倍

**但它站在一个坏位置上。** 这是本案的核心张力：公司质量 ★4.0，行业结构 ★1.5。

### 6.2 护城河评分卡

| 护城河类型 | 评分 | 核心证据 | 趋势 |
|-----------|------|---------|------|
| 网络效应 | ★★☆☆☆ | **无跨客户网络效应**（单租户 + zero retention）；有租户内效应；Agent Library + MCP 生态是弱生态效应 | ↗ 缓升 |
| **转换成本** | ★★★★☆ | 153 连接器重配、权限映射重建、双图谱重新养成、**自定义 agent 全部作废**、跨 8+ 嵌入点重接、合规重认证。**减弱因素**：Glean 官方支持 agent 导入导出 + 力推 MCP 开放标准——**在用开放性换增长，代价是自削锁定** | → 张力中 |
| 品牌心智 | ★★★★☆ | Fast Company 全球最创新 Top 10（2025）、Gartner 双认可、Forbes AI 50；媒体已默认定位为"the Microsoft Copilot rival" | ↗ |
| **数据壁垒** | ★★☆☆☆ | **最容易被误判的一维**。单租户 + 客户自有云 + zero retention **从物理上阻断**跨租户复利——**Glean 卖的正是"我碰不到你的数据"**。真正壁垒是连接器工程资产，**是工程壁垒伪装成数据壁垒** | → |
| 监管合规 | ★★★★☆ | SOC 2 + 单租户 + 三大洲数据驻留 + 零留存协议 + 专职 CISO + 零 CVE。**Protect+ 把合规做成了可单独收费的 SKU** | ↗ 显著强化 |
| 规模经济 | ★★★☆☆ | 正向：连接器/Waldo 研发成本跨客户摊薄。**负向：单租户托管削弱基础设施规模经济；FDE 服务随客户线性增长** | ↗ 缓升 |
| 技术壁垒 | ★★☆☆☆ | 基础模型全部外购；arXiv 产出 0；专利未能核验。**唯一真壁垒是「权限 × 预计算索引」的乘积** | ↘ |

**综合护城河：★★★☆☆（3.3）——运营/工程型护城河，非技术型。加权半衰期约 3 年。**

核心判断：**不在数据，也不在网络效应，而在"转换成本 + 合规 + 品牌"三角。** 这是一条足够宽以支撑高增长和高毛利、**但不足以抵御超大平台长期挤压**的护城河。

### 6.3 权限层壁垒的可复制性（本案的技术核心）

Glean 官方文档亲口点破自建方案三大死因：ACL 镜像进 vector DB、权限**永续同步**负担、"**Get any of that wrong and you leak documents**"。架构级佐证：权限层级是 Storage 团队与企业文档**同级的一等存储对象**；产品内提供 `--act-as <restricted-user>` 工具主动验证不越权。

| 复制方 | 难度 | 判断 |
|--------|------|------|
| 创业公司 | 9–15 个月做头部 10 连接器；**3–5 年**做到 153 连接器 × 企业级正确性 | 难，且需付出真实客户现场调试的学费 |
| **微软** | **已经不需要复制**——Entra ID + Purview 对自家数据原生、零延迟 | **Glean 在微软地盘上做的是微软根本不必做的事**。但微软**院墙之外**（Salesforce/ServiceNow/Workday）无动机也无对等能力 |
| OpenAI/Anthropic | 目前是真实短板；组织基因与"给 Salesforce 权限模型写第 47 个 edge case"天然排斥 | **Glean 相对模型厂商唯一的实质防线** |

侵蚀概率：**微软 60–70%，OpenAI 25–35%。**

## 7. 投资论点

### 🟢 看多逻辑

1. **真 SaaS 毛利，且 LLM 成本是收入而非成本** 🟢 — 官方定价文档逐字确认原价透传 + take-rate 抽成；Waldo 自研模型便宜 10 倍；Premium 模型硬性围栏。订阅毛利 85–92%。**这是对"AI 应用毛利会被推理成本吃掉"共识的有据反例。**
2. **已自我完成定价转型，主动对冲了席位模式的结构性威胁** 🟢 — Agent 创建免费、运行计费。人少了席位收入降，agent 多了 credit 收入升。三重证据（文档 + 两个 billing/finance 岗位 JD）。
3. **创始人是本案最强环节** 🟢 — 前 Google Distinguished Engineer + **Rubrik 已 IPO**，罕见的"被公开市场验证过的连续创业者"。创业动机来自 Rubrik 内部真实痛点。三年公开发言无被打脸记录。
4. **高管配置明确指向 IPO** 🟢 — COO 是现役 NYSE 审计委主席 + 前上市公司 CEO/CFO；Wellington 领投 F 轮；CMO 有 Pure Storage IPO 经验。
5. **估值曲线越融越便宜** 🟢 — 200x → 24x，基本面跑赢价格。跑道充裕（约 2.75 年），2026 年无被迫融资压力。
6. **安全防守出乎意料地扎实** 🟢 — **零 CVE**（NVD 全库检索）、SOC 2、单租户隔离、零留存协议、专职 CISO。把"一次泄露即灭顶"的尾部风险压到约 10%。
7. **中立性是结构性优势** 🟢 — 生态中立、模型中立、部署中立（SaaS/VPC/客户自有 AWS 或 GCP，vs Copilot 的 Azure-only）。**这三条是微软的商业模式约束而非技术缺陷，因此微软不会修复它们。**
8. **二级市场一年 +59.3%**，是溢价而非折价 🟡

### 🔴 看空逻辑

1. **行业结构罕见恶劣，五力全部 4+** 🟢 — 买方是三个万亿平台、进入壁垒被 MCP 拉低、替代品免费捆绑。**增长的收益将主要被平台方捕获。**
2. **Rule of 40 ≈ 0** 🔴 — 增速 103% + FCF 利润率 −103%，可比组内最低。年净现金消耗推算约 $160M。
3. **招聘规模停滞 16 个月，与"15 个月营收三倍"直接冲突** 🟢 — 107(2025-03) → 102(2026-07)。**全篇最硬、最需解释的数据点。**
4. **MCP 已彻底商品化连接器护城河** 🟢 — 规范原文确认。任何引用"100+ 连接器"的分析已过期。
5. **公开市场已对这个赛道判决** 🟢 — Coveo 2.0x（一年 −49%）、Elastic 3.8x（一年 −29%）。24x 与 2–4x 之间只由增长率守卫。
6. **三个带高管署名的旗舰客户案例被整体删除** 🟢（删除属事实，原因未知）— Deutsche Telekom、Pure Storage、Cro Metrics，全站 grep 为 0。
7. **主动从应用降级为管道** — 甘做 ChatGPT/Claude 的 MCP 上游。**管道的定价权系统性低于应用**，且这个转向从未对外宣告。
8. **数据壁垒是伪命题** 🟢 — 单租户从物理上阻断跨租户复利，每个新客户都是冷启动。

### ⚖️ 哪一方更有说服力？

**这是三家研究中唯一一个我认为看多方论据更硬的案子——但结论仍是"观望"，原因在价格而非公司。**

看多方的证据类型明显更强：官方定价文档（一手）、Greenhouse API（一手）、NVD 检索（一手）、官方 ARR 新闻稿（一手）。看空方的核心论据（行业结构、平台碾压）虽然正确，但**是关于未来的推演，而非已发生的事实**。

**唯一例外是"招聘停滞 16 个月"**——这是看空方唯一一条一手硬证据，且直接与增长叙事冲突。**它可能是本案最早出现的裂缝，也可能只是运营杠杆的证明。目前无法区分。**

**决定性的判断分歧在时间尺度**：
- **未来 12–24 个月**：看多方赢。增长真实、毛利健康、现金充裕、IPO 路径清晰。
- **未来 3–5 年**：看空方赢。平台捆绑无结构性解法，护城河半衰期约 3 年。

### Top 3 核心风险

1. **平台捆绑无结构性解法** — Glean 只能靠跑得更快，这是一场没有终点的赛跑。唯一的结构性防线是"中立性"，而这恰恰是微软和 OpenAI 商业模式上无法复制的。
2. **Rule of 40 ≈ 0 意味着增长是唯一的估值支柱** — 增速一旦掉到 40% 以下，倍数重估会是断崖式的（参照 Coveo 从 40%+ 增长跌到 11%，倍数塌到 2x）。

## 13. 总结

Glean 是本框架研究过的三家 AI 公司里，唯一一家**生意本身经得起推敲**的。Snorkel 是软件叙事掩盖服务现实，Handshake 是真实增长被夸大成色，而 Glean 的问题不在于它是什么，而在于它站在哪里。

拿到官方定价文档是本次研究的转折点。它一次性回答了两个最关键的质疑：per-seat 会不会被 agent 时代颠覆——已经被颠覆了，由 Glean 自己动的手，Agent 创建免费、运行计费，人少了席位收入降、agent 多了 credit 收入升；LLM 推理成本会不会吃掉毛利——不会，因为 Model Hub 按 provider 原价透传，Glean 还在客户的 LLM 账单上再抽一个百分比。加上自研 Waldo 把最高频的检索规划环节成本降了十倍，订阅毛利在 85% 以上。这是"AI 应用公司毛利必然被推理成本侵蚀"这一共识的一个有据可查的反例。

$7.2B 对应 18.7x NTM 收入，与 2026 年高增长 SaaS 的中位数几乎完全重合，而它的增速是那一组的 3.7 倍。估值曲线从 C 轮的 200x 一路压到今天的 24x，基本面持续跑赢价格——这与 2021 年泡沫的形态正好相反。

但五力全部打到 4 分以上，是罕见的恶劣结构。Glean 的护城河是「权限 × 预计算索引」的乘积，真实存在、需要三到五年复制，但对微软而言这是一件它在自己地盘上根本不必做的事。而 Rule of 40 等于零意味着增长是唯一的估值支柱——Coveo 从 40% 增速跌到 11% 时，倍数塌到了 2x。

最需要解释的一条数据是：营收十五个月翻三倍，在招岗位却停滞了十六个月。它可能是运营杠杆的证明，也可能是增长减速的先行指标。**在一级 $7.2B，这个价格基本公允；在二级约 $10B，安全边际已经归零。**
